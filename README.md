# 王宮の密命 Online

2〜5人で遊べる、サーバー権威型のオンラインカードゲームです。ルームを作成し、5文字のコードを友達に送るだけでPC・スマートフォンから対戦できます。

## ローカル起動

Node.js 20以上が必要です。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。動作確認は `npm test` です。

アクセスキーを有効にする場合は、起動前に環境変数 `ACCESS_KEY` を設定してください。未設定ならローカル開発用としてアクセスキー画面を省略します。アクセスキーはリポジトリやソースコードへ直接記載しないでください。

## Renderへのデプロイ

このリポジトリには `render.yaml` を同梱しています。

1. Renderで **New → Blueprint** を選ぶ
2. このGitHubリポジトリを接続する
3. `render.yaml` の設定を確認して作成する
4. デプロイ完了後に表示される `https://...onrender.com` が公開URL

ビルドは `npm install`、起動は `npm start`、ヘルスチェックは `/health` です。Socket.IOは同じWebサービス内で動作し、限定公開に使う `ACCESS_KEY` 以外の環境変数は不要です。無料プランでは無通信後の初回アクセスに時間がかかる場合があります。

限定公開にする場合は、Renderの **Environment** で `ACCESS_KEY` を追加します。設定後のデプロイでは、正しいキーを入力したブラウザだけがルーム操作を行えます。キーはタブを閉じるまで `sessionStorage` にのみ保持され、サーバーはキーをクライアントへ配信しません。誤入力はIPアドレスごとに15分間10回までです。

## 遊び方

全16枚から1枚を伏せて除外し、各プレイヤーへ1枚配ります。ランダムな先手から時計回りに進行します。手番では1枚引き、2枚から1枚を先に場へ公開します。対象型カードは公開後に対象（兵士は予想値も）を選んで効果を解決します。脱落者は残り手札を公開しますが、その効果は発動しません。

- 生存者が1人になれば、その人が1点
- 山札の最後の1枚を引いた手番の効果解決後、生存者の手札を公開
- 最大値が同じ場合は、公開済みカードの数字合計が大きい人が勝者
- それも同じ場合は同点者全員が1点
- 設定した規定点（初期値3点）を先取するとマッチ勝利

### カード（全16枚）

| 数字 | 名前 | 枚数 | 効果 |
|---:|---|---:|---|
| 1 | 兵士 | 5 | 相手の手札の数字を1〜8から予想。的中すると対象が脱落 |
| 2 | 道化 | 2 | 相手の手札を使用者だけが確認 |
| 3 | 騎士 | 2 | 相手と残り手札を秘密比較し、小さい方が脱落。同値は生存 |
| 4 | 僧侶 | 2 | 次の自分の手番開始まで、他者のカード効果の対象外 |
| 5 | 魔術師 | 2 | 残り手札を効果なしで公開して捨て、新しい1枚を引く |
| 6 | 将軍 | 1 | 相手と残り手札を秘密に交換 |
| 7 | 大臣 | 1 | 所持中、ドロー直後の2枚合計が12以上なら即脱落 |
| 8 | 姫 | 1 | 通常プレイまたは魔術師で捨てると脱落 |

対象型カードは僧侶の加護を受けている相手を選べません。有効な相手がいない場合、カードは出せますが効果はありません。将軍で受け取った姫・大臣は交換時には脱落を起こしません。

- 道化で確認したカードは、使用者本人にだけ専用の大きな確認画面で表示され、秘密メモにも残ります。
- 「残り枚数」では、全員の公開済みカードを全16枚から差し引き、各カードが未公開領域に残っている可能性枚数を確認できます。手札・山札・除外札の内訳を推測または公開するものではありません。
- 入室時に10色から名前色を選択でき、盤面の名前とアイコンに反映されます。
- 8種類すべてにオリジナルのカードイラストがあり、手札・公開札・確認画面・一覧で共通表示されます。

## カード画像の差し替え

画像は `public/assets/cards/` にカード別の固定ファイル名で配置しています。同じ名前のWebPへ上書きするだけで差し替えできます。ファイル対応表、推奨サイズ、今回の生成プロンプトは [CARD_ART.md](CARD_ART.md) を参照してください。

魔術師の交換時に山札が空なら、ゲーム開始時に伏せて除外した1枚を代わりに引きます。最終公開で姫を見せても脱落しません。

## 通信・切断仕様

手札、効果、比較、対象、得点はすべてサーバーで検証・管理します。公開ログと本人専用の秘密メモは別データとして配信します。ブラウザ更新や一時的な回線切断では保存済みの再接続トークンを使い、60秒以内なら同じ席に復帰できます。60秒を超えると対戦中は脱落、待機中は退出扱いになります。ホストが戻らない場合は接続中の次プレイヤーへホスト権限が移ります。

画面上部の「タイトルへ戻る」はいつでも使用できます。待機中は即退出、対戦中は脱落扱いとなり、ホストが戻った場合は接続中の次プレイヤーへホスト権限を移します。
